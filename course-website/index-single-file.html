      Frequently Asked Questions

      What do I need to know before joining?

      Basic Python and school-level linear algebra, calculus and probability. Day 1 sets up the full tool stack, so no prior deep-learning experience is needed.

      How is each day organised?

      Every day has a concept session followed by a hands-on lab with a concrete outcome, such as training cnn.py on MNIST or building a RAG chatbot. Each day is linked to a table, figure or code listing in the handbook.

      What is the SDG capstone?

      In Days 27–30 you choose an SDG-aligned project, define a measurable KPI, build the data pipeline and baseline, train a hybrid CNN / LSTM / Transformer / MoE system, deploy it as a Streamlit app or API, and present it on demo day for expert review.

      Which tools will I use?

      PyTorch, Hugging Face, timm, Ultralytics YOLO, MLflow, Kafka/MQTT, FastAPI, Triton, vLLM, SHAP and Fairlearn, among others. See the production stack.

      What does the fee include?

      The 30-day program, the complete reference handbook (Parts A–E), six tested PyTorch programs, 60 project briefs with solution hints, 17 SDG industry blueprints with the production-stack guide, and a personal capstone review by the program director.
