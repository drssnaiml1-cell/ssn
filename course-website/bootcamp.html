FAQ

Frequently asked questions

What do I need to know before joining?

Basic Python and school-level linear algebra, calculus and probability. Day 1 sets up the complete tool stack, so no prior deep-learning experience is required.

How is each day organised?

Each day has a concept session followed by a hands-on lab with a concrete outcome, for example training cnn.py on MNIST or building a RAG chatbot with LoRA fine-tuning.

What is the SDG capstone?

In Days 27–30 you choose a UN Sustainable Development Goal project, define a measurable KPI, build the data pipeline and a baseline, train a hybrid CNN / LSTM / Transformer / MoE system, deploy it as a Streamlit app or API, and present it on demo day for expert review.

What does the fee include?

INR 1,00,000 per participant covers the 30-day program, the complete reference handbook (Parts A–E), six tested PyTorch programs, 60 project briefs with solution hints, 17 SDG industry blueprints with the production-stack guide, and a personal capstone review by the program director.
